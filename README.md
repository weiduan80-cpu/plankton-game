# 浮游生物 · 进化大逃杀

单文件 HTML5 网页小游戏，手机（iPhone / 安卓）和电脑浏览器打开即玩。

## 在线试玩

https://weiduan80-cpu.github.io/plankton-game/

## 玩法

- **电脑**：方向键 ← ↑ ↓ → 控制游动方向，无法停下
- **手机**：手指按住屏幕拖动，浮游生物朝手指方向游
- 咬住其他浮游生物的**尾巴尖**来吞噬体节、长大进化
- 千万别撞别人的**脑袋**；保护好自己的尾巴，只剩一颗头时被咬即死
- 出生后有 3 秒闪烁保护期
- 三档难度：简单 / 中等 / 超难，所有生物慢速起步并逐渐加速

## 宝石

| 宝石 | 效果 |
|------|------|
| ◆ 死亡宝石（暗红菱形） | 碰到立即死亡，无敌可免疫 |
| ⚡ 加速宝石（黄色闪电） | 速度 +10%，持续 10 秒 |
| ♥ 生命宝石（粉色爱心） | 额外一条命，死亡后从初始状态重生 |
| ★ 无敌宝石（青色五角星） | 10 秒内免疫一切吞噬和伤害 |

## 本地运行

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建。
